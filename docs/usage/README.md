# Usage

For people installing the skills and running them on their own projects.

- [Install the skills](install.md) — clone, `make install`, and what happens per skill
- [Document a project with these skills](documenting-a-project.md) — running `/docs-init`, `/docs-update`, `/docs-edit` and `/docs-search`, choosing between them, and recording your docs preferences
- [Collect telemetry from your Claude Code sessions](telemetry.md) — `make enable-telemetry`, the local dashboards it brings up, and turning it off again
- [Read the telemetry dashboards](telemetry-dashboards.md) — a panel-by-panel tour of the two Grafana dashboards, with screenshots

Working on the skills themselves is a different job — see [CONTRIBUTING.md](../../CONTRIBUTING.md).
